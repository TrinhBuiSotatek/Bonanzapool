## I. Operation: API close trigger, on-chain LP liquidation, and event detection

> **Note (v5):** The close flow is triggered by the investor calling `POST /internal/exbot/close` (body: `{"bot_id":"<id>"}`, role: operator). The API synchronously sets `lifecycle_state='lp_closing'`, `status='closing'`, and enqueues the close flow. The `lp_leg_exec` worker then calls `BnzaExVault.redeem(tokenId)` on-chain — LP is liquidated and LP-portion USDC is returned to the investor in the same on-chain tx. `RedemptionEvent` is emitted and picked up by the event watcher to continue the async hedge-close chain.
